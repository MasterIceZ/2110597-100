# Project 1: VGA Shooting Game

A simple shooting game made with Verilog and shown on a VGA screen. Move the red player left or right and hit the yellow enemies. The player shoots automatically, and new enemies appear in random spots.

## Controls

- `ui_in[1]`: Move left
- `ui_in[2]`: Move right
- `rst_n = 0`: Reset the player position
